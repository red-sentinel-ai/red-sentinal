# Sui Sentinel Landing Page Strategy & Content Plan

## Executive Summary

Based on competitor analysis of Lakera.ai, Prompt.security, HiddenLayer.com, and Mindgard.ai, this plan outlines new landing pages to position Sui Sentinel as the leading crowdsourced AI red teaming platform. Unlike competitors offering "security as a service," we offer a marketplace that scales through community participation and crypto incentives.

---

## 1. Competitor Analysis Summary

### Lakera.ai
- **Positioning**: Enterprise AI security platform
- **Key Differentiator**: Continuous learning from 1M+ hackers via Gandalf game
- **Target**: Fortune 500, ultra-low latency focus
- **Weakness**: Centralized service model doesn't scale efficiently

### Prompt.security
- **Positioning**: Multi-layer AI defense (Employees, Apps, Code Assistants, Agents)
- **Key Differentiator**: MCP Gateway for agentic AI security
- **Target**: Enterprises with shadow AI concerns
- **Weakness**: Traditional SaaS pricing, no community incentives

### HiddenLayer.com
- **Positioning**: Full lifecycle AI security platform
- **Key Differentiator**: End-to-end (Identify → Analyze → Protect → Firewall)
- **Target**: CISOs, Federal, Financial Services
- **Weakness**: Heavy enterprise sales cycle, no crowdsourced component

### Mindgard.ai
- **Positioning**: Technical AI risk identification
- **Key Differentiator**: Specific attack vectors (Jailbreaking, Extraction, Evasion, etc.)
- **Target**: Security teams, technical buyers
- **Weakness**: Limited positioning on scalability and incentives

### Sui Sentinel's Unique Position
- Only **crowdsourced** red teaming marketplace
- Only platform with **on-chain verification** (TEE attestations)
- Only platform with **instant trustless payouts**
- **Dual-sided marketplace**: Both defenders AND attackers are incentivized
- **Self-reinforcing flywheel**: More attacks = more data = stronger defense
