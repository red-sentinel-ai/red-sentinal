Sui Sentinel frontend application

## Getting Started

First, run the development server:

We are using bun as a package manager, if you don't have bun installed, install bun by following instructions from

https://bun.sh

Create a new file `.env` and add all the required environment variables.

```bash
bun install
```

```bash

bun dev
```

Install slush wallet from https://slush.app/ as slush wallet is being used for login in Sui Sentinel.
